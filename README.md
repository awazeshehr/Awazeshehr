## Sentiment Analysis (VADER)

This project runs sentiment analysis on complaint text on the backend (Node.js spawns a Python script).

### Requirements

- Python (available on PATH as `python`)
- Python packages:
  - `vaderSentiment`
  - `requests` (installed automatically as a dependency of `vaderSentiment`)

Install the Python dependencies:

```bash
python -m pip install vaderSentiment
```

### How it works

- Python script: `server/scripts/analyze_sentiment.py`
- Backend integration: `server/routes/complaints.js` (runs on complaint submit and stores `sentimentLabel` + `sentimentScore`)

### Quick check

```bash
python server/scripts/analyze_sentiment.py
```

If Python/VADER is not available at runtime, the backend falls back to a local (non-Python) analyzer so sentiment does not default to Neutral for every complaint.
